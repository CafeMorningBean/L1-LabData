## 1. 미션 1: 화난 고객에게 사과 메일

### Lv.1: 그냥 말하기
**새 채팅**에 복사해서 붙여넣기
```
배송 지연 사과 메일 써줘.
```

### Lv.2: + 역할
**새 채팅**에 복사해서 붙여넣기
```
너는 카페 브랜드 '모닝빈' 온라인몰의 5년 차 고객응대 팀장이야.
배송 지연 사과 메일 써줘.
```

### Lv.3: + 조건 + 형식 (3원칙 완성)
**새 채팅**에 복사해서 붙여넣기
```
[역할]
너는 카페 브랜드 '모닝빈' 온라인몰의 5년 차 고객응대 팀장이야.

[조건]
- 상황: 고객이 친구 생일 선물로 '원두 선물세트'를 주문했는데, 택배사 사정으로 배송이 3일 늦어져 생일이 지난 뒤에 도착하게 됐어. 고객은 별점 1점 리뷰를 남길 만큼 화가 나 있어.
- 꼭 넣을 것: 진심 어린 사과, 새 도착 예정일(10월 8일), 보상(다음 주문 때 쓸 수 있는 음료 무료 쿠폰 2장)
- 하지 말 것: 택배사 탓하며 변명하기, 과장된 표현
- 분량: 본문 5~6문장

[형식]
- 메일 제목 1줄
- 본문은 '사과 → 상황 설명 → 보상 안내 → 맺음말' 순서로 문단을 나눠 줘.
```

## 2. 미션 2: 엉망진창 회의 녹취록 → 깔끔한 회의록

```
[역할]
너는 모닝빈 본사 기획팀의 꼼꼼한 회의록 담당자야.

[조건]
- 아래 녹취록에는 잡담이 섞여 있어. 업무와 관련 없는 이야기는 빼 줘.
- 녹취록에 없는 내용은 절대 추가하지 마. 정해지지 않은 건 '미정'이라고 써 줘.

[형식]
1. 회의 제목과 한 줄 요약
2. 결정된 사항 (글머리표)
3. 할 일 표 (열: 담당자 | 할 일 | 마감)
4. 다음 회의 안건

---
[회의 녹취록: 모닝빈 가을 신메뉴 회의]
박팀장: 자, 가을 신메뉴 얘기 시작합시다. 후보가 밤 라떼랑 고구마 라떼였죠?
이영희: 네, 근데 고구마 라떼는 작년에 경쟁사가 크게 해서 좀 식상할 것 같아요.
김민수: 저도 밤 라떼 찬성이요. 아 근데 어제 야구 보셨어요? 9회에 역전…
박팀장: 민수 씨, 야구는 점심때 합시다. 그럼 밤 라떼로 가는 걸로 하죠.
이영희: 가격은 5,300원 어때요? 바닐라라떼랑 같게요.
박팀장: 좋아요, 그걸로 확정. 출시일은 10월 20일로 합시다.
김민수: 그럼 저는 대학가 매장용 홍보 포스터 시안을 다음 주 수요일까지 만들게요.
이영희: 저는 밤 페이스트 거래처 두 곳 견적을 금요일까지 받아 볼게요.
박팀장: 아, 시음회도 하면 좋겠는데… 이건 다음 회의 때 다시 얘기합시다.
김민수: 참, 신촌점 에어컨 또 고장 났대요.
박팀장: 그건 제가 시설팀에 전달할게요. 오늘 회의 끝!
```
